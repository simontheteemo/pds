After the rebase, `src/Modules/PDS.Sales` and `src/PDS.Shared/Settings/LocalDate.cs` must exist, and `dotnet build PDS.slnx` must be green. Retarget the draft PR's base to `main` at the same time.

**Goal:** A per-project monthly cashflow forecast, computed on read from costs (actuals plus the remaining forecast cost phased straight-line to completion) and sales (settled and contracted settlements). It's shown as a chart and a table, with peak funding as the headline figure.

**Architecture:**
- A new module, `src/Modules/PDS.Cashflow`, owns **no table**.
- It calls three additive Contracts queries, which Task 1 adds:
  - `IPortfolioQueries.GetSchedule`
  - `ICostQueries.GetProjectCostPosition`
  - `ISalesQueries.GetContractedSales`
- A pure `CashflowCalculator` builds the monthly series.
- One endpoint, `GET /api/cashflow/projects/{projectId}`.
- The web app adds `web/src/features/cashflow`: a lazy-loaded page at `/projects/:id/cashflow` with a Mantine `CompositeChart`, plus a `ProjectCashflowCard` on the project detail page.

**Tech Stack:** Same as the foundation and the other modules. **New web packages:** `@mantine/charts@9.6.3` and `recharts` (exact pin, ≥ 3.2.1; Task 4).

**Spec:** `docs/superpowers/specs/2026-10-14-cashflow-design.md`. Reference implementations to mirror:
- `src/Modules/PDS.Costs`: `ProjectLookup`, a report-style GET endpoint, DTO style.
- `src/Modules/PDS.Contractors/Data/ContractQueries.cs`: a Contracts query implementation registered as a singleton.
- `web/src/features/costs`: `CostReportPage`, `ProjectCostsCard`, `CostFiguresStrip`.

- All foundation constraints apply:
  - net10.0 and central package versions.
  - Only `Contracts/` and the `*Module` class are public.
  - ProblemDetails errors; camelCase JSON with string enums.
- **Module rule:** `PDS.Cashflow` uses only `PDS.Portfolio.Contracts`, `PDS.Costs.Contracts` and `PDS.Sales.Contracts`, and never internal types of those modules.
- **No new tests** (user directive). Verify with:

  - In web/: `npm run gen:api && npm run typecheck && npm run lint && npm run build`.

  - The manual checks each task names. Run the API with `--urls http://localhost:5087` and Vite with `--port 5197`. Reuse DynamoDB Local on :8000 if it's already running; never stop it.
- All amounts are `decimal` in `LocaleOptions.Currency`.

  - No other rounding.

## Review Focus

1. **Reconciliation.** `totals.outflow + totals.unscheduledCost` must equal the cost report's `totals.actual + totals.forecastToComplete`, to the cent. `totals.inflow + totals.unscheduledSales` must equal Sales `summary.contractedValue`. Check both with curl and jq against seeded data.
2. **Schedule edge cases:**
   - No completion date → all remaining cost is in `unscheduledCost`, and no forecast cost months exist.
   - Completion in a past month → the whole remaining cost is in the current month.
   - Start in a future month → phasing begins at the start month, not the current month.
   - Start after completion → a single month (the start month).
   - Remaining 1000.00 over 3 months → 333.33, 333.33, 333.34.
3. **Overdue and unscheduled sales.** A Conditional or Unconditional sale whose settlement month is past lands in the current month. One with no settlement date appears in `unscheduledSales[]` and in no month. A Settled sale stays in its (past) settlement month.
4. **Empty and unknown projects.** A project with no costs, no sales and no dates → 200 with exactly one month (the current month, all zeros), `peakFunding` null, and the UI empty state. An unknown project id → 404.
5. **Negative actuals and peak funding.** A credit note (negative actual) reduces that month's outflow, and the series still reconciles. `peakFunding` is the positive magnitude of the most negative cumulative value, with the **first** month it occurs. It's null when cumulative never drops below 0.

namespace PDS.Costs.Data;

internal sealed class CostQueries(CostStore store) : ICostQueries

    public async Task<ProjectCostPosition> GetProjectCostPosition(ProjectId projectId, CancellationToken ct)

// Domain/Month.cs
namespace PDS.Cashflow.Domain;

internal static class Month
{
    public static DateOnly Of(DateOnly d) => new(d.Year, d.Month, 1);
    public static DateOnly Max(DateOnly a, DateOnly b) => a > b ? a : b;
    public static DateOnly Min(DateOnly a, DateOnly b) => a < b ? a : b;
    /// <summary>Inclusive count of months from <paramref name="from"/> to <paramref name="to"/> (both first-of-month).</summary>
    public static int Count(DateOnly from, DateOnly to) => ((to.Year - from.Year) * 12) + to.Month - from.Month + 1;
    public static IEnumerable<DateOnly> Range(DateOnly from, DateOnly to)
    {
        for (var m = from; m <= to; m = m.AddMonths(1))
            yield return m;
    }
    public static string Key(DateOnly m) => m.ToString("yyyy-MM", System.Globalization.CultureInfo.InvariantCulture);
}

// Domain/CostPhasing.cs
namespace PDS.Cashflow.Domain;

/// <summary>Straight-line phasing of the remaining cost (spec §3). Replace this to support per-line profiles.</summary>
internal static class CostPhasing
{
    public static IReadOnlyDictionary<DateOnly, decimal> StraightLine(decimal remaining, DateOnly from, DateOnly to)
    {
        var result = new Dictionary<DateOnly, decimal>();
        if (remaining == 0m)
            return result;
        var end = Month.Max(to, from);
        var n = Month.Count(from, end);
        var share = Math.Round(remaining / n, 2, MidpointRounding.AwayFromZero);
        var i = 0;
        foreach (var m in Month.Range(from, end))
            result[m] = ++i == n ? remaining - (share * (n - 1)) : share;
        return result;
    }
}
```

// Domain/CashflowMonth.cs
namespace PDS.Cashflow.Domain;
internal sealed record CashflowMonth(
    DateOnly Month, decimal CostActual, decimal CostForecast, decimal SalesSettled, decimal SalesForecast, decimal Cumulative)
{
    public decimal Outflow => CostActual + CostForecast;
    public decimal Inflow => SalesSettled + SalesForecast;
    public decimal Net => Inflow - Outflow;
}

// Domain/CashflowResult.cs
using PDS.Sales.Contracts;
namespace PDS.Cashflow.Domain;
internal sealed record CashflowResult(
    DateOnly? ScheduleStart, DateOnly? ScheduleCompletion,
    IReadOnlyList<CashflowMonth> Months,
    decimal UnscheduledCost,
    IReadOnlyList<ContractedSale> UnscheduledSales,
    decimal? PeakFunding, DateOnly? PeakFundingMonth);

// Domain/CashflowCalculator.cs
using PDS.Costs.Contracts;
using PDS.Portfolio.Contracts;
using PDS.Sales.Contracts;
namespace PDS.Cashflow.Domain;

internal static class CashflowCalculator
{
    public static CashflowResult Calculate(
        DateOnly today, ProjectSchedule schedule, ProjectCostPosition cost, IReadOnlyList<ContractedSale> sales)
    {
        var current = Month.Of(today);
        var start = schedule.ActualStart ?? schedule.PlannedStart;
        var completion = schedule.ActualCompletion ?? schedule.PlannedCompletion;

        var costActual = new Dictionary<DateOnly, decimal>();
        foreach (var a in cost.Actuals)
            Add(costActual, Month.Of(a.Date), a.Amount);

        IReadOnlyDictionary<DateOnly, decimal> costForecast = new Dictionary<DateOnly, decimal>();
        var unscheduledCost = 0m;
        if (completion is null)
            unscheduledCost = cost.ForecastToComplete;
        else
        {
            var from = Month.Max(current, Month.Of(start ?? today));
            costForecast = CostPhasing.StraightLine(cost.ForecastToComplete, from, Month.Of(completion.Value));
        }

        var salesSettled = new Dictionary<DateOnly, decimal>();
        var salesForecast = new Dictionary<DateOnly, decimal>();
        var unscheduledSales = new List<ContractedSale>();
        foreach (var s in sales)
        {
            if (s.SettlementDate is not { } date)
                unscheduledSales.Add(s);
            else if (s.Status == ContractedSaleStatus.Settled)
                Add(salesSettled, Month.Of(date), s.SalePrice);
            else
                Add(salesForecast, Month.Max(Month.Of(date), current), s.SalePrice);
        }

        var touched = costActual.Keys.Concat(costForecast.Keys).Concat(salesSettled.Keys).Concat(salesForecast.Keys)
            .Append(current).ToList();
        if (start is { } s0) touched.Add(Month.Of(s0));
        if (completion is { } c0) touched.Add(Month.Of(c0));
        var first = touched.Min();
        var last = touched.Max();

        var months = new List<CashflowMonth>();
        var cumulative = 0m;
        decimal? peak = null;
        DateOnly? peakMonth = null;
        foreach (var m in Month.Range(first, last))
        {
            var row = new CashflowMonth(m, costActual.GetValueOrDefault(m), costForecast.GetValueOrDefault(m),
                salesSettled.GetValueOrDefault(m), salesForecast.GetValueOrDefault(m), 0m);
            cumulative += row.Net;
            months.Add(row with { Cumulative = cumulative });
            if (cumulative < 0m && (peak is null || -cumulative > peak))
            {
                peak = -cumulative;
                peakMonth = m;
            }
        }

        return new CashflowResult(start, completion, months, unscheduledCost,
            unscheduledSales.OrderBy(u => u.UnitIdentifier, StringComparer.OrdinalIgnoreCase).ToList(), peak, peakMonth);
    }

    private static void Add(Dictionary<DateOnly, decimal> map, DateOnly m, decimal amount) =>
        map[m] = map.GetValueOrDefault(m) + amount;
}
```

internal static async Task<Results<Ok<ProjectCashflow>, NotFound>> Handle(
    Guid projectId, IPortfolioQueries portfolio, ICostQueries costs, ISalesQueries sales,
    TimeProvider clock, IOptions<LocaleOptions> locale, CancellationToken ct)
{
    var pid = new ProjectId(projectId);

}

```tsx
import '@mantine/charts/styles.css';
import { CompositeChart } from '@mantine/charts';
import { useConfig } from '../../shared/config';
import { monthLabel, type CashflowMonth } from './types';

export function CashflowChart({ months, currency }: { months: CashflowMonth[]; currency: string }) {
  const { culture } = useConfig();
  const compact = new Intl.NumberFormat(culture, { style: 'currency', currency, notation: 'compact', maximumFractionDigits: 1 });
  const full = new Intl.NumberFormat(culture, { style: 'currency', currency, maximumFractionDigits: 0 });
  const data = months.map((m) => ({
    month: monthLabel(m.month, culture),
    In: m.inflow,
    Out: -m.outflow,
    Cumulative: m.cumulative,
  }));
  return (
    <CompositeChart
      h={320}
      data={data}
      dataKey="month"
      withLegend
      referenceLines={[{ y: 0, color: 'gray.6' }]}
      valueFormatter={(v) => full.format(v)}
      yAxisProps={{ tickFormatter: (v: number) => compact.format(v) }}
      series={[
        { name: 'In', color: 'teal.6', type: 'bar' },
        { name: 'Out', color: 'red.6', type: 'bar' },
        { name: 'Cumulative', color: 'blue.6', type: 'line' },
      ]}
    />
  );
}
```

Check the prop names (`referenceLines`, `valueFormatter`, `yAxisProps`, `series[].type`) against the installed `@mantine/charts` typings, and adjust to match them. Typecheck is the arbiter.
